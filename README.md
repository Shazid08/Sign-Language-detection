# 🤟 Sign Language Detection using CNN & OpenCV


## 📘 Overview
The **Sign Language Detection System** is a real-time vision-based machine learning application that recognizes **American Sign Language (ASL)** alphabets using **Convolutional Neural Networks (CNN)** and **OpenCV**.  
Developed as part of a research initiative at **Jain (Deemed-to-be University)**, this project demonstrates how artificial intelligence and computer vision can bridge communication gaps for the deaf and hard-of-hearing community.

🔗 **Published Paper:** [International Journal of Innovative Research in Science, Engineering and Technology (IJIRSET)](https://www.ijirset.com/upload/2023/april/255_Sign1.pdf)  
📄 **Volume 12, Issue 4, April 2023** | **Impact Factor:** 8.423 | **DOI:** [10.15680/IJIRSET.2023.1204255](https://doi.org/10.15680/IJIRSET.2023.1204255)

---

## 🎯 Objectives
- Develop a **real-time ASL recognition prototype** using deep learning.  
- Enable effective communication between deaf-mute individuals and others.  
- Implement **CNN-based classification** of hand gestures captured via webcam.  
- Use **OpenCV** for image preprocessing, segmentation, and contour detection.  
- Achieve high accuracy in sign language prediction using modern AI methods.

## 🧩 System Workflow
1. **Data Collection:** ASL alphabet images captured via webcam or imported from Kaggle.  
2. **Preprocessing:** Noise removal, thresholding, and contour detection using OpenCV.  
3. **Feature Extraction:** CNN layers automatically learn important spatial features.  
4. **Model Training:** Model trained on labeled hand gesture datasets.  
5. **Real-Time Detection:** Webcam captures gestures and classifies them live using CNN.  

---

## 🧠 Key Features
✅ **Real-Time Detection** — Instant recognition of ASL alphabet gestures.  
✅ **Deep Learning Model (CNN)** — Learns visual patterns for accurate classification.  
✅ **OpenCV Integration** — Enables hand detection, segmentation, and tracking.  
✅ **85% Accuracy** — Achieved using CNN + Mediapipe pipeline.  
✅ **Accessible Design** — Built to support inclusive communication.

## 🧠 Methodology Summary
- **Approach:** Image-based recognition (preferred over sensor-based systems).  
- **Algorithm:** CNN for feature extraction and classification.  
- **Tools Used:** TensorFlow, OpenCV, Pandas, NumPy, Tkinter.  
- **Data Source:** Kaggle ASL dataset and real-time webcam captures.  
- **Result:** The trained model recognized ASL letters with 85% accuracy in real-time.
